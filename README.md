# 📚 Smart Study Buddy

A Python-based study planning and progress tracking web application that helps students organize their study plans, manage goals, track completed tasks, and monitor their learning progress.

## ✨ Features

- **Study Plans** — Create and manage study schedules.
- **Goal Management** — Set study goals, target hours, and deadlines.
- **Study Tasks** — Organize learning activities and track task completion.
- **Progress Tracking** — Record study hours and monitor progress.
- **Analytics Dashboard** — Visualize study performance and progress.
- **Calendar** — View and navigate study schedules by date.
- **Reminders** — View reminders for upcoming study activities.
- **Input Validation** — Validate user inputs and display helpful error messages.

## 🛠️ Tech Stack

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, Jinja2 templates
- **Database:** SQLite
- **Version Control:** Git and GitHub

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/suryakarthika2912/smart-study-buddy.git
cd smart-study-buddy
```

### 2. Create a virtual environment

**Windows:**

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

Open the local URL displayed in your terminal in your web browser.

## 🎯 Project Objective

The goal of Smart Study Buddy is to help students build consistent study habits by combining planning, goal setting, task management, and progress analysis in one application.
